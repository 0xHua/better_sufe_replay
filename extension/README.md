# 上财空中课堂 · 回放增强（MV3 扩展 v0.1）

把一个「不好用的课程回放页」变成自己的播放器。当前版本是**可用骨架 + 自诊断探针**：
先在你已登录的浏览器里跑一次，把诊断结果发回来，我再按真实 DOM 和接口精调。

## 安装

1. 打开 `chrome://extensions/`（Edge 是 `edge://extensions/`）
2. 右上角打开 **开发者模式**
3. 点 **加载已解压的扩展程序**，选择本目录 `extension/`（就是含 `manifest.json` 的那一层）
4. 建议把它固定到工具栏

> 每次我改了代码，你回到扩展页点那个「刷新 ↻」按钮即可，不用重装。

## 用法

1. 先在 `https://dm.sufe.edu.cn` 正常登录（学号密码只填给学校，扩展不碰）
2. 打开任意一节回放的页面，**点一下播放**（嗅探需要页面真的去取流）
3. 点扩展图标，会看到：
   - 登录态（是否读到 `x-cas-token`）
   - 嗅到的视频直链，每条可「播放 / 复制」
   - 「用增强播放器打开」→ 在新标签页用自带播放器播放（倍速、书签、记忆进度、截图、画中画）
4. 点 **导出诊断** → 下载一个 `sufe-replay-diag-*.json`，**把这个文件发我**

诊断文件里**不含** token 原文（只记录长度和前 8 位），也不含视频 URL 的签名参数。

## 为什么是「复用登录态」而不是「代登录」

- 代登录＝扩展要持有学号密码，一旦扩展被投毒就是全校账号泄露，且大概率撞上验证码/风控。
- 本方案＝只读你自己浏览器里已经存在的 `localStorage['x-cas-token-app']`，
  没有后端、没有服务器、凭据不出本机。视频文件本身是公开可播的（已实测：无签名、无 Cookie 也 200），
  所以播放环节压根不需要鉴权。

## 目录

```
extension/
├── manifest.json          MV3 清单
├── src/
│   ├── content.js         内容脚本：读 token、嗅探直链与接口、DOM 结构摘要
│   ├── background.js      后台：token/直链/接口存储，开播放器页
│   ├── popup.html/js      工具栏面板与诊断导出
└── player/                增强播放器（由 ../../player/index.html 拆分而来）
    ├── index.html         ?src=<mp4>&title=<标题>
    ├── player.css
    └── player.js
```

重新生成 player 三件套（改了 `../player/index.html` 之后）：

```powershell
python tools/split_player.py
```

拆分的必要性：MV3 扩展页默认 CSP 是 `script-src 'self'`，**内联 `<script>` 会被拒绝执行**，
所以原来的单文件播放器必须拆成外部 js/css 才能搬进扩展。

## 已知限制

- 只有 `<video>` 能被直接接管；若平台用自定义渲染/Canvas 播放，需要另想办法。
- 若播放器在跨域 iframe 里，嗅探会失效（当前 iframe 是同域的，应该没问题，待验证）。
- 进度、书签存在本机 `chrome.storage.local`，不上传。
