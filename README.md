### 界面功能

- 左侧四组筛选：视图 / 学期 / 学院 / 教师
- 六列列表：课程 / 教师 / 学院 / 上课时间 / 教室 / 回放次数；点行展开详情
- 详情里的「回放画面」：按节次给出 PPT / 屏幕 与 教师画面；
- 播放器：单屏 / 双屏可切，位置可选左右、上下、小窗；时轴同步 + 手动时间差（±20 秒，0.1 秒步进）；每一路独立音量；倍速 0.5–3、全屏；快捷键只有 `空格` / `←→` ±5 秒
- 播放器右侧栏：**概要 / 知识要点 / PPT 帧 / 字幕** 四个标签，每条带时间点的内容点一下就跳过去；字幕跟着播放走。
- 顶栏 `下载①` / `下载②`：直接下载当前两路 MP4
