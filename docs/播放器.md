# 播放器（单屏 / 双屏 + 侧栏）

扩展内的播放页：`app/player/index.html`，由课程详情的「回放画面」点进去。

## 入口

课程列表 → 点开一行 → 回放画面 → 选节次：

- **双屏看（屏幕 + 教师）** —— 一次把两路画面都给播放器（`?src=…&src2=…&c1=…&c2=…`），默认左右并排
- **播放** —— 只开这一路（`?src=…&c1=…`）
- **原片** —— 直接开 MP4，交给浏览器自带播放器（链接还是那个地址，不做加工）

`c1` / `c2` 是这一路画面的 contentId，侧栏的概要、知识要点、PPT 帧、字幕都靠它去取。

## 播放栏下面那一排

| 组 | 作用 |
|---|---|
| 屏幕 | `1` / `2`：单屏或双屏。只有一路地址时 `2` 是灰的 |
| 位置 | `左右` / `上下` / `小窗`。选 `小窗` 后右边多出 `① 小窗` / `② 小窗`：**想哪一路缩成小窗就点哪一路**；小窗是画中画式浮在画面上，**按住它拖到任意位置**，松手记住（位置按 0–1 存，换窗口大小也不会跑偏） |
| 时轴同步 | 勾上就跟随第一路；`−` `+` 每次 0.1 秒（范围 ±20 秒），`归零` 一把抹平；拖动滑块时只改数字，松手才真正 seek |
| 音量 | ① ② 各一条，互相独立：可以只给教师画面静音、只留屏幕画面的声音 |

## 右侧栏（概要 / 知识要点 / PPT 帧 / 字幕）

**单屏默认开，双屏默认收**（双屏时两路各 640 宽，再挤 340 就太小了）；顶栏「侧栏」按钮随时手动开关，手动动过一次之后就不再自动跟着单/双屏走。全屏时侧栏不显示。

四个标签都只放**入库时就算好的静态数据**，不是打开页面现生成：

| 标签 | 接口 | 内容 |
|---|---|---|
| 概要 | `GET /learn/v1/homepage/course/keywordAndAbstract?videoId=` | 本节概要正文 + 10 个关键词 |
| 知识要点 | `GET /rman/v1/intelligent/select/knowledge/summary?contentId=` | 20 段章节（标题 / 时间 / 说明）+ 79 个知识点 |
| PPT 帧 | `GET /rman/v1/entity/file/screenshot?page=1&size=100&contentId=` | 这一节的 PPT 截图，每张带时间点 |
| 字幕 | `GET /rman/v1/search/webvtt?contentId=…&voice=true&isSysAuth=true&lang=source` | 真 VTT，这一节 2179 句 |

- 每一条带时间点的内容**点一下就跳过去**（章节、知识点、PPT 帧、字幕都行）。
- 字幕默认「跟着播放走」：当前这句高亮并滚到中间，点任意一句就跳过去并接管高亮。
- 数据一律走 background 取（内存缓存 30 分钟，**不落盘**），页面自己再缓存一层；切标签不重复请求。
- 只认「屏幕画面」那一路的 contentId —— 教师画面那路没有语音转写，摘要/字幕/知识点都是空的。

## 下载

顶栏右侧 `下载①` / `下载②`，分别下载当前两路 MP4。走扩展的 `chrome.downloads`，直接落到浏览器下载目录，不经过任何第三方。



- 第一路是**主时钟**：进度条、时间、播放/暂停、倍速都认它。
- 第二路每帧（`requestAnimationFrame`）比较 `第二路时间 - (第一路时间 + 手动时间差)`，**偏差超过 0.25 秒才 seek 一次**，避免一直 seek 把片子拖卡。
- 实测：两路一起播，偏差稳定在 0.01 秒内；把时间差调到 +1.2 秒后，实测差值保持在 1.2 秒附近（±0.25 秒的容差内）。
- 两路时长本来就差一点（同一节课两个录制文件，实测 9899.59 秒 vs 9900.00 秒），所以「时间差」不是装饰，是刚需。

## 现在有什么

| 功能 | 说明 |
|---|---|
| 播放 / 暂停 | 按钮、点画面、空格；双屏时两路一起动 |
| 进度条 | 可点可拖；底层灰条是已缓冲区间；悬停出现拖柄 |
| 时间 | `当前 / 总长`，超过 1 小时自动 `h:mm:ss` |
| 倍速 | 0.5 / 0.75 / 1 / 1.25 / 1.5 / 1.75 / 2 / 2.5 / 3，两路同速 |
| 音量 | 每一路一条独立滑块 + 独立静音 |
| 全屏 | 右上角按钮；全屏时只留画面和控制条 |
| 深浅色 | 顶栏右侧，跟着记忆 |
| 侧栏 | 顶栏「侧栏」；概要 / 知识要点 / PPT 帧 / 字幕 四个标签，点了就跳 |
| 下载 | 顶栏 `下载①` / `下载②`，直接存 MP4 |

## 快捷键（只有三个）

| 键 | 作用 |
|---|---|
| `空格` | 播放 / 暂停 |
| `←` | 后退 5 秒 |
| `→` | 前进 5 秒 |

音量快捷键 `↑` `↓` **已取消**（容易误触，且双屏下不知道该调哪一路），音量只在底部那排里调。
在输入框、下拉框里按方向键不会被拦截（会先判断焦点元素）。

## 记忆

`localStorage['sufe.player.prefs']` 存 `{rate, theme, count, mode, sync, off, vol1, vol2, mute1, mute2, pipTarget, pipX, pipY}`，下次打开自动恢复布局、音量与小窗位置；地址里的 `?mode=` `?count=` `?sync=` `?off=` 优先于记忆值（小窗目标与位置不受影响，永远按记忆走）。

## 已知限制

- 不记忆播放进度：关掉再打开从 0 开始。
- 没有学号水印层：学校播放器叠的 `昵称，学号` 是溯源标记，我们这边还没画上去 —— 这是下一步第一件要补的事。
- 进度条拖动受源文件限制：单文件 1.2–2.4 GB，往没缓冲过的远处拖会等 1–3 秒；双屏就是两份流量。
- 小窗是「贴在播放器里面」的浮层，不是系统级浮窗：拖不出浏览器窗口，也不能盖在别的程序上（Document PiP 还没做）。
- 侧栏里的摘要 / 字幕 / 知识点是**学校入库时算好的**，读的是 `屏幕画面` 那一路；换成只有教师画面的节次就是空的。
- 侧栏只缓存到内存，关掉页面就没了，下次打开要重新读（1–2 秒）。
