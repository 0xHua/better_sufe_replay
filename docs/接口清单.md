# 上财「空中课堂」回放站 接口清单

> 采集方式：CDP（Edge 156，`--remote-debugging-port=9222`）+ `tools/cdp_capture.js` 被动录制，
> 在真实登录态下刷新详情页与列表页各一次。原始响应体存于 `probe/extract/`。
> 鉴权为**浏览器 Cookie 会话**（`S1_rman_sid` 等），`window.x_cas_token` 实测为 `false`，
> 说明当前这套前端走的是 Cookie，而不是签名 header。

域名：`https://dm.sufe.edu.cn`　　参考页面：`/learn/videoreview?id=3644`

---

## 1. 课程列表（回放总览）

```
GET /learn/v1/course/video/review/-1
    ?type=-1&courseName=&teacherName=&campus=&academicBuilding=&classroom=
    &orderBy=join_time&isDesc=true&page=1&size=12&schoolYear=2026-2027&semester=秋季
```

响应 `data.total` = 可看回放的课程数（本账号 10 门），`data.results[]` 每项：

| 字段 | 含义 |
|---|---|
| `id` | 课程页主键（`3644`），进详情页要用 |
| `courseId` | 32 位课程 ID（`a958f298…`） |
| `courseName` / `teacherNames` / `collegeNames` | 课程名、教师、学院 |
| `classroomNumber` / `xqShowName` / `jxlShowName` | 教室 / 校区 / 楼 |
| `courseTimeData` | `["周一 3-5节"]`，展示用 |
| `playbackCount` | 回放点开次数（热度） |
| `showSemester` | `2026-2027学年第一学期` |
| `hasVideo` | 1 = 有录像 |

> 另有 `GET /learn/courseSearch`（22 KB）返回全站课程搜索索引，可做本地模糊搜索。

## 2. 一节课的结构（周次 → 课时 → 三路画面）

```
GET /learn/v1/course/recording/video/info
    ?courseId=a958f29815aa40b3806c2be5fda5a79c
    &id=3644&schoolYear=2026-2027&semester=秋季
```

```
data.recordingVideoInfoShows[]              # 按周分组
├── week / startTime / endTime / ifStart
└── recordInfoDetailList[]                  # 该周的具体课时
    ├── weekDay / weekDate / section / realSection
    └── videoInfoList[]                     # ★ 每次课最多 3 路画面
        ├── videoId                         # 32 位，后面换直链要用
        ├── videoName                       # 含「教师画面 / 屏幕画面 / 学生画面」
        ├── scheduleId
        └── startTime / endTime
```

同时返回 `coursePublicSectionsList[].frames`：哪几路的 `ifPublic = 1`（学生可见）。

**三种画面**：`教师画面`（讲台机位）、`屏幕画面`（PPT/演示）、`学生画面`（教室全景）。
一次课通常有 2–4 个 `videoId`，其中 `scheduleId` 可能重复（同一场录制）。

## 3. ★ 直链（关键：播放地址就藏在这里）

```
POST /rman/v1/entity/download/fileinfo
Content-Type: application/json
Body: ["86c7b4cb76924b409e1b96c23dce8434", "951c1a6f167d468ca565cd76c4289b1f"]
```

响应：

```json
{ "success": true, "data": [ {
    "contentId": "86c7b4cb76924b409e1b96c23dce8434",
    "entityName": "…第7周…_教师画面",
    "seat": "教师画面",
    "downloadAddress": [
      "/bucket-z/ROLE_r_group_manager_cc6ca7cfa6d6477fa0fd8a4a76486ccf/video/2026/10/12/三教502/86c7b4cb….mp4"
    ],
    "fileGroups": [
      { "groupName": "videogroup",       "showName": "原格式",  "files": [{ "fileSize": "2.42GB" }] },
      { "groupName": "videogroup_proxy", "showName": "流媒体",  "files": [{ "fileGuid": "c04438d0…" }] }
    ]
} ] }
```

- `downloadAddress[0]` 是**相对路径**，拼 `https://dm.sufe.edu.cn` 即播放地址
- 一次可传多个 contentId，批量换直链
- 播放器本身不是用这个接口拿地址的（它是自己拼的），但两者结果**完全一致**，见下节

**验证过的直链性质**（早期探测）：明文 MP4、`Accept-Ranges: bytes`、`moov` 在文件头（fast-start）、
`Access-Control-Allow-Origin: *`、无 query 签名、**不带 Cookie 也返回 200** —— 存储层公开读，
所以播放环节不依赖登录态，只有「拿 contentId」这一步需要登录。

## 4. 白送的富数据（现有页面基本没用好）

| 接口 | 内容 | 对重构的价值 |
|---|---|---|
| `GET /rman/v1/search/webvtt?contentId=…&voice=true&isSysAuth=true&lang=source` | **字幕 VTT**，4934 行，~2 小时全覆盖 | 播放器可显示字幕、全文搜索跳转 |
| `POST /rman/v1/smart/voice/select` `{contentid, metadataType:"model_sobey_smart_voice_"}` | 语音识别全文 + 时间戳（410 KB） | 同上，字幕的原始素材 |
| `GET /rman/v1/entity/file/screenshot?page=1&size=50&contentId=…` | **PPT 帧索引**，118 张，含 `filePath` 与 `nextInPoint`（时间点） | 幻灯片导航、按页跳转 |
| `GET /learn/v1/homepage/course/keywordAndAbstract?videoId=…` | 关键词 + 摘要 | 章节标记 |
| `POST /rman/v1/search/new/relation/videos` `{courseNumber, week, weekDay, section, scheduleIds, isGetCut}` | 索贝媒资元数据：`labels`（如 生产力/生产关系/…）、`describe`（自动摘要）、`voice_density`、`keyframe_`、`filesize`、`duration`(ticks) | 封面图、标签云、难度评估 |
| `POST /learn/online/classroom/knowledge/point/list` | 知识点列表（2.8 KB） | 知识点时间轴 |
| `GET /learn/online/classroom/replay/rate?courseId=…&sectionId=7:Monday:3-5` | 评分 | 可选 |
| `GET /sup/v1/getcoursetimes` | 课表时间 | 列表排序 |

## 5. 进度、心跳与统计（重构时必须决定怎么处理）

| 接口 | 频率 | 说明 |
|---|---|---|
| `POST /learn/online/classroom/flow/log` | **约每 20 秒** | 心跳/行为日志，平台判「在看」的主要依据 |
| `GET /learn/v1/learningsituation/onlineClassRoom/userWatchActive?courseId=` | 每 30 秒 | 主动轮询观看状态 |
| `GET /learn/online/classroom/watch/duration?courseId=&sectionId=` | 页面加载 | 已观看时长 |
| `POST /learn/v1/history/add` | 页面加载 | 学习历史 |
| `GET /unifiedplatform/v1/setting/watermark` | 页面加载 | 水印开关配置 |

另：`copyrightSetting.copyright = 1`，播放器用 `watermark.js` 叠加 `nick_name + "，" + user_code`
（学号水印，`watermark_density` / `watermarkLocation` / `wholeShowWaterMark` 控制），属**溯源机制**。

## 6. 页面内的现成变量

| 变量 | 内容 |
|---|---|
| `window.courseBackInfo` | 课程全量信息（含 `frames`、`copyrightSetting`） |
| `window.loginUserInfo` | 当前用户（`user_code`、`nick_name`、`roles:["r_student"]`、`organizations`） |
| `window.x_cas_token` | 实测 `false` —— 这套站点不吃 header token |
| `localStorage.video_review_config` | `{"selectedScreen":"屏幕画面"}` 记住你上次看哪一路 |
| `sessionStorage.learn_user` / `hasLogin` | 登录态缓存 |
| `window.MultiViewPlayer` | 双路同步播放器（1.8 MB 内核） |

## 7. 已知限制

- `sup/v1/interdispatch/getcoursebehaviorsummary` → **403**（学生无权限，行为统计只给老师）
- `rman/v1/smart/voice/keyword/match` → **403**（同上）
- 教师画面的 `keywordAndAbstract` 为空、`asr_status=0`：**只有屏幕画面做了语音识别**
  ⇒ 字幕、摘要、知识点基本都挂在「屏幕画面」那一路
- 单文件 1.77–2.42 GB，`H264 2M 1920×1080`，无多码率；远距离 seek 需 1–3 秒

---

## 8. 一句话总结

**「列出课程 → 拿课时 contentId → 批量换直链」三跳就够，全部走 Cookie 会话，
不需要逆向签名、不需要拦截播放器。** 现有页面把这些数据都拿到了，只是呈现得不好用。
