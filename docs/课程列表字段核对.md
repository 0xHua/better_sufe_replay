# 课程列表接口：返回值核对

对象：`GET /learn/v1/course/video/review/-1?type=-1&…&page=1&size=12&schoolYear=2026-2027&semester=秋季`

最近一次实测（2026-10-26 10:49，详情页同源请求）：

| 条件 | HTTP | `data.total` | 结论 |
|---|---|---|---|
| 带登录 Cookie | 200 | **10** | 正常返回 |
| 不带 Cookie | 200 | **0** | 静默返回空数组，**不是 401** |
| 带 Cookie，但 URL 的 `semester` 写错 | 200 | 0 | 同上 |

所以前端必须能区分「真的没课」和「没登录」——两者都是 200 + 空数组。判断依据：
`window.loginUserInfo` 是否存在，或另调一个会 401 的接口（如 `recording/video/info`）探一下。

响应外层：`{ status: 200, message: "OK", data: { page, size, total, totalPage, results: [...] } }`
`results[]` 每项 **38 个字段**，逐个核对如下。

## 直接可用（已在新页面里用上）

| 字段 | 样例 | 用途 |
|---|---|---|
| `id` | `4844` | 详情页主键，进课时要用 |
| `courseId` | `5e6aeafd184e4ce484d84dd230e11fdf` | 32 位课程 ID，调课时接口 |
| `courseName` | `常微分方程` | 列表主标题 |
| `courseNumber` / `serialNumber` | `1_0603_26271` | 副标题 |
| `teacherNames` | `戴媛媛,张鋆` | 教师列（多人用逗号分隔，**要拆**） |
| `collegeNames` | `数学学院` | 学院列 / 侧栏筛选 |
| `courseTimeData` | `["周五 3-5节"]` | 上课时间列 |
| `campus` | `武东路校区` | 位置 |
| `jxlShowName` | `武东路阶梯教室` | 楼 |
| `classroomNumber` | `阶梯教室九` | 教室 |
| `showSemester` | `2026-2027学年第一学期` | 学期分组 |
| `playbackCount` | `30` | 回放热度，可排序 |
| `hasVideo` | `1` | 有无录像 |
| `collect` / `collectNumber` | `false` / `0` | 收藏态（可直接做收藏按钮） |

## 可用但要注意

| 字段 | 说明 |
|---|---|
| `teachers` / `colleges` / `majors` | **JSON 字符串**，`{"2014000056":"刘单"}`，要 `JSON.parse`；扁平版是 `teacherNames` 等 |
| `courseTime` | JSON 字符串，逐周列表 `[{week,weekDay,section}]`，可算「共 16 次课」 |
| `teacherList` / `collegeList` | `[{value,code}]`，筛选用的稳定 code |
| `collectData` | ⚠️ 内含 `userCode`（学号），**渲染前必须剔除**；`app/index.html` 的 `normalize()` 按 17 字段白名单裁剪，天然不带它 |
| `joinTime` | 加入时间戳（13 位），默认排序用 |
| `latestFestival` | `3-5`，最近一次节次 |
| `siteCode` | `S1`，站点标识 |
| `live` | `null`（这次都是回放，无直播） |
| `recordedCourses` / `educational` | 都是 `0`，含义未确认，未使用 |
| `liveAuthority` / `showBackAuthority` | 权限字段，后者 `false` 但回放可看，暂按不可靠处理 |
| `checkOnlineCourseAllListByJoin` | `false`，未使用 |

## 这个接口没有、要另取的

| 缺什么 | 去哪拿 | 是否需要登录 |
|---|---|---|
| 每门课有几节课 / 每节课的录像 | `GET /learn/v1/course/recording/video/info?courseId=…&id=…` | **要** |
| 每节课的画面分路（教师/屏幕/学生） | 同上 `videoInfoList[]` | 要 |
| 播放直链 | `POST /rman/v1/entity/download/fileinfo` | **不要** |
| 字幕 VTT | `GET /rman/v1/search/webvtt?contentId=…` | **不要** |
| PPT 帧（118 张） | `GET /rman/v1/entity/file/screenshot?contentId=…` | **不要** |
| 关键词 / 摘要 | `GET /learn/v1/homepage/course/keywordAndAbstract?videoId=…` | 实测可取 |
| 知识点 | `POST /learn/online/classroom/knowledge/point/list` | 要 |
| 已观看时长 | `GET /learn/online/classroom/watch/duration?courseId=…&sectionId=…` | 要 |
| 封面图 / 课程简介 / 学分学时 | 本接口没有；`/learn/courseSearch` 或统一平台，待查 | — |

## 一句话

列表这一层**够用**：课程名、教师、学院、时间、地点、热度、收藏、进详情的主键全都有。
缺的是「往下钻」的那一层（几节课、几路画面、直链），那部分本来就该在第二步取。
唯一要提防的是**匿名返回空数组而不是报错**——这会让「没登录」看起来像「没课」。
