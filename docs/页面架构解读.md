# 上财空中课堂 · 回放详情页 架构解读

> 依据：用户提供的 `源代码.txt`（625 行，114 KB，即 `/learn/videoreview/{courseId}` 的 SSR 外壳页），
> 以及我另外拉取的 `video_review_detail_layout.js`（773 KB，v2610221141）。

## 一、结论先行

你发的这份 HTML **不是真正的回放页面**——它只是一个外壳。页面渲染完成后，`#main` 里只有一个空荡荡的挂载点：

```html
<div id="main" class="container">
  <component v-else
    :is="sysModulesObj.target_customer === 'sufe' ? 'review_student_sufe' : (...)"
    :course_info="courseInfo" :week_list="weekList"
    :user_info="loginUserInfo" :copy_right="copyrightSetting">
  </component>
</div>
```

真实的播放器、章节列表、PPT、笔记、弹幕……全部由 Vue 动态组件 `review_student_sufe` 在运行时渲染，
组件代码在 `video_review_detail_layout.js` 里。**播放地址也不在 HTML 中**，是运行时接口取的。

## 三、从 bundle 里读到的关键机制（附证据）

### 1. 播放器配置（xgplayer）

```js
b = { id:"main_player", urls:e,
      playbackRate:[.5,.75,1,1.25,1.5,2],
      fluid:!0, closeInactive:!0, isLive:!!t,
      autoplay:!0, videoInit:!0, screenShot:!0, ... }
```

- 倍速是**前端白名单** 6 档，上限 2×。
- `urls`（复数）⇒ 支持多路视频（教师画面 / 屏幕共享），这也是 `multi_view_player` 存在的理由。
- `screenShot:!0` ⇒ 原生就允许截图，说明 canvas 没有被污染（与实测 `Access-Control-Allow-Origin: *` 吻合）。

### 2. ★ 现成的直链出口：组件会把播放地址 postMessage 给父窗口

```js
getUrls: function (e) {
  this.videoUrls = e;
  window.parent && window.self !== window.top && setTimeout(function () {
    try {
      var t = { urls: e || [] };
      window.parent.postMessage({ action: "GET_PLAYER_DATA", data: t }, "*");
      console.log("播放器数据已发送到父窗口", t);
    } catch (e) { console.error("发送播放器数据失败:", ...) }
  });
}
```

播放器组件在 iframe 中运行时，会**主动**把 `{urls:[...]}` 用 `postMessage(…, "*")` 发给父窗口。
这意味着扩展不需要 hook `fetch`、不需要解析 DOM、不需要逆向接口——**监听 `message` 事件即可拿到直链**。
这是整个项目里最重要的一条发现，取链难度从「中」掉到「极低」。

### 3. 播放地址来自 `getVideoUrls()`

```js
case 31: t.next = 34, e.getVideoUrls(h, c);
case 34: e.videoUrls = t.sent;
```

异步取，且带 `resourceChangeToken` 防竞态。接口路径是拼接出来的，bundle 里搜不到 `videoreview/` 字面量，
说明路径常量在上层（`common.js` 或全局 http 封装）里。

### 4. 学号水印（版权保护，必须保留）

```js
b.watermark_density = ...;  // 以及
(y.user_info.nick_name, "，").concat(y.user_info.user_code)   // 姓名，学号
```

`window.copyrightSetting = {"copyright":1}`、`window.showWatermark = …watermark || false`。
水印内容是「姓名，学号」，支持动态水印、密度、位置。

⇒ **这是溯源机制，不是装饰。重构时绝不移除或遮挡**，否则就从"改善体验"变成了"协助盗录"。

### 5. 权限与进度

- 无权限时中断初始化并报 `"您没有观看回看权限！"`。
- `window.VIDEOTIMEUNIT = 10000000` ⇒ 进度单位是 **1e7 ticks/秒**（.NET TimeSpan），后端按 tick 记进度。
- `window.recordOpenDelayHours = 4` ⇒ 回放延迟 4 小时开放。
- `window.wsPrefix` ⇒ WebSocket，用于直播/在线状态。

## 四、对重构方案的影响

| 原假设 | 实际情况 | 方案变化 |
|---|---|---|
| 需要 hook 播放器或逆向接口取链 | 组件自己 `postMessage` 吐出 urls | 主路径改为监听 `message`；performance 嗅探降为兜底 |
| 播放器在页面 DOM 里 | 在 iframe（`multi_view_player`）里 | 「接管播放」= 替换 iframe 的 src，或在 iframe 外加一层自己的控制条 |
| 倍速 3× 可用 | 前端白名单只到 2× | 自建播放器可突破，但进度回传仍按 tick |
| 页面结构复杂需要重排版 | 外壳只有导航 + 一个挂载点 | 重排版成本极低：外壳可原样保留，只替换 `#main` 内容 |
